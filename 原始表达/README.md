# 原始表达档案

本目录保存主体在特定时间、语境下的原始表达，作为后续解读、比较与理论修订的依据。

## 使用原则

1. **原话优先**：原始表达尽量逐字保存，不擅自润色、纠错、压缩或替换术语。语音识别造成的错字、重复、停顿和不完整句子也可能是语境证据；如需校订，只能另设校订稿，不能覆盖原文。
2. **来源可追溯**：记录日期、对话主题、来源位置或可用链接。无法确认的元数据标记为未知，不猜测。
3. **解释分离**：主体原话、AI 初步解读、主体后续自我解读、比较与修订必须分栏或分文件保存，不能混成同一段。
4. **允许多重解释**：同一原话可以在不同时间产生不同解释。旧解释不因新解释出现而自动删除，应保留版本与理由。
5. **具体问题优先**：邀请主体解读时，优先提供一个具体原句、一个具体概念或一个具体分歧，不一次性抛出大量抽象问题。
6. **术语不预设权威性**：主体使用的词可能是自定义概念，也可能与学术、公众或词典用法不同。应记录其语境定义，再比较外部定义，不得直接以词典释义覆盖主体用法。
7. **不把解释当成原意**：AI 的理解是待检验假设；主体确认、修正或拒绝后，分别记录，不回写伪装成原始表达。

## 建议条目结构

- 原始表达（逐字）
- 时间与语境
- 当时提出的问题
- AI 初步解读（标记提出者与日期）
- 主体自我解读（由主体补充）
- 解释差异与争议
- 与既有命题的关系
- 后续修订记录

## 目录定位

本目录不是命题库，也不是权威定义库。它是思想发生与变化的来源档案，为命题库提供可回溯材料，并保留主体在不同时段的理解差异。
