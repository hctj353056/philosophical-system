# 决策日志

## 初始版本

- 决策：建立分层命题网络，并明确区分命题层级、类型、状态与依赖关系。
- 原因：使理论能够逐步推导、回溯前提、接受反驳并进行局部重构。
- 限定：初始命题统一标记为 `proposed`，不把工作假设包装成已证明结论。
- 初始命题：L0.1、L1.1–L1.8、L2.1。
- 备注：本初始包是对先前哲学讨论的整理草案，尚需用户逐项审查与修订。

## 0.2.0 · 四层架构整合（2026-10-30）

### 决策 1：确立层级符号主权
- 决策：`L` 前缀专指论证层级；概念体系改用 `E0-E3`，心智模型改用 `S0-S3`，四层认知框架保持具名。
- 原因：`L0/L1/L2` 被三种不同含义同时占用。具体危害是"1 级概念"会被误读为"L1 命题"——前者是"由 0 级概念组合而来"，后者是"需要论证的基础前提"，等于把复合当基础。
- 限定：本决策改变的是符号，不改变任何命题内容。

### 决策 2：认知基线改挂 L1.2，不挂 L1.1
- 决策：概念体系「认知基线」的依赖关系挂 `L1.2`（个体模型不等于世界）。
- 原因：认知基线主张"对象的性质取决于所在范畴"，说的是 `Mᵢ` 的内部表征结构；`L1.1` 管的是 `W` 的存在与独立性。二者分属表征层与本体层，不构成对立。误认的根源是两套体系之间原本零依赖登记。
- 限定：为此在 `L1.1` 增补「推论限制」，在 `L1.2` 增补「下游细化」，双向加边界声明，防止再次误读。

### 决策 3：新增 L2.2 规格层接口
- 决策：把"认识论如何落到可运行系统"显式建模为一条 L2 命题。
- 原因：既有 190KB 工程规格与 L 层命题之间没有任何接口。规格化过程会引入可判定性、一致性即正确、完备性等未论证假设，若不显式标注，规格会冒充认识论。
- 限定：`L2.2` 状态为 `proposed`，未经实际运行检验。

### 决策 4：Mᵢ 补时间下标与自我指涉维
- 决策：`Mᵢ` 改写为 `Mᵢ(t)`，自我指涉部分记作 `Mᵢ[Mᵢ]`。
- 原因：原定义中 `Mᵢ` 是静态结构，说不清同一主体不同时刻的模型变化属于哪一层；也无处安放"我对我的模型的模型"。这两处缺口由建模对象层（四层认知框架）指出——它是本次整合中 O 层对 L 层的实质补强。
- 影响：`L1.3` 的"可修订"因此获得落点——修订预设可比较的前后状态。

### 决策 5：provenance-index 增加 proposition_id 字段
- 决策：在 `id` 之后新增 `proposition_id`，把来源记录挂到具体命题上。
- 原因：原表有 6 条来源记录（P001-P006），但没有任何字段指向命题，导致从命题无法反查到来源——**有记录但不可达**，与"每条命题都应记录其直接依据"的承诺不符。
- 限定：P007-P011 标为 `needs-source`，其具体对话出处仍需用户补充，不得视为已完成的溯源。
