# 整合版 · 四层架构 v0.2.0

> 由 `philosophical-system` 0.1.0 与既有三套框架（概念体系 v1.0、心智模型完整版、四层认知框架）整合而成。
> 整合日期：2026-10-30。

## 这是什么

一个四层架构。每层只管一件事，谁都不越界。

```
L  认识论地基   本仓库                → L0 / L1 / L2
   ↕ 接口① 表征结构细化（挂 L1.2）
E  概念词汇表   概念体系 v1.1          → E0 / E1 / E2 / E3
   ↕ 接口② 概念落成可执行规则
S  运行规格     心智模型完整版          → S0 / S1 / S2 / S3
   ↕ 接口③ 规格约束建模对象
O  建模对象     四层认知框架            → 具名，不编号
```

| 层 | 回答什么问题 | 不回答什么 |
| --- | --- | --- |
| **L** | 世界怎么分、什么算知道、错了怎么改 | 系统怎么跑 |
| **E** | 我用什么词思考、词与词怎么组成 | 现实是否独立于主体 |
| **S** | 系统具体怎么跑、什么算跑对了 | 什么算真实 |
| **O** | 建模谁、记什么、怎么从日志反推规则 | 世界如何运作 |

## 整合的核心结论

**四套体系没有理论冲突，只有两类假象，加一处依赖挂错。**

1. **层级符号撞车**：`L0/L1/L2` 被三种不同含义同时占用。已确立符号主权——`L` 归论证层级，概念体系改 `E`，规格层改 `S`，建模对象保持具名。
2. **两个层次混在一层里谈**：概念体系的"认知基线"讲性质取决于范畴，`L1.1` 讲现实不取决于主体。看似对立，实为本体层 vs 表征层。一句话：**现实的独立性 ≠ 我的表征方式的唯一性。**
3. **依赖挂错**：认知基线应挂 `L1.2`（个体模型不等于世界），不挂 `L1.1`。两套体系原本零依赖登记，才有这次误认。
