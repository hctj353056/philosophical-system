# philosophical-system

哲学体系：以可追溯、可质疑、可修订的命题网络，逐步构建个人哲学框架。

## 核心原则

- 本仓库是研究与建模过程的记录，不是已经证明的完整哲学体系。
- 命题状态默认为 `proposed`（提出中），记录不等于证明。
- 区分真实世界、个体意义世界与主体间公共模型。
- 区分逻辑有效性、经验支持与实践有效性。
- 对每个重要命题记录依据、推导、适用范围、反例和修订条件。
- 允许局部重构，警惕循环论证、概念偷换和把共识当真理。

## 从哪里开始

1. 阅读 `SYSTEM.md`，了解总体架构。
2. 阅读 `META/rules.md`、`META/proposition-types.md` 和 `META/revision-policy.md`。
3. 查看 `indexes/proposition-index.csv` 了解命题清单。
4. 从 `propositions/L0/` 和 `propositions/L1/` 阅读基础命题。
5. 通过 `indexes/dependency-index.csv` 查看命题依赖关系。
6. 将争议、反例和修订理由记录在 `reviews/` 与 `history/`。

## 状态提醒

本仓库中的命题是当前工作假设和初步论证草案。尤其是“现实独立于主体”“存续是认识活动的发生条件”等主张，仍需要明确论证或经验支持。
