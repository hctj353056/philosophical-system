_本层对应既有资产「概念体系 v1.0」（云盘 `知识库/概念/`）。整合后改称 E 层，层级符号由「0/1/2/3 级」改为 `E0/E1/E2/E3`，避免与 L 层的论证层级、S 层的形式化层次撞车。_

## 一、本层的职责边界

本层描述的是**个体意义世界 `Mᵢ` 的内部表征结构**：我用什么词思考、词与词如何组成、哪些词对我是不可再分的。

**本层不对真实世界 `W` 的存在与独立性作任何断言。** 相关立场由 `L1.1`（现实不完全取决于特定主体的认识）承载。本层讨论"性质取决于所在范畴""红色对灵镜不是 0 级"这类主张时，说的是表征粒度与切分方式，不是对象由主体创造。

→ 接口登记见 `元规则/跨体系接口.md` 接口①，挂靠 `L1.2`（个体模型不等于世界），**不挂** `L1.1`。

## 二、层级含义（与 L 层严格区分）

| 本层符号 | 含义 | 与 L 层的关系 |
| --- | --- | --- |
| `E0` | 对当前认知基线不可再分的概念 | 与 L0「论证起点」无关 |
| `E1` | 由两个及以上 E0 概念组合生成 | 与 L1「基础命题」无关 |
| `E2` | 依赖 E1 及以下的复合结构 | 与 L2「模型」无关 |
| `E3` | 跨 E1/E2 的上层综合 | 无对应 |

**注意**：`E` 编号表示的是**组合深度**，不表示论证地位，也不表示重要性。E0 不比 E1 更"根本"，只表示在当前认知基线下它不再需要被拆解。

## 五、例证附录：苹果（原 v1.0 的 0 级概念，现为 E-06 的案例）

苹果的 0 级属性"红色"，对具备正常色觉的主体来说不可再分，不需要被解释。

但对先天盲人来说，"红色"是需要被解释的概念——它由"波长""视网膜锥细胞响应""他人的语言描述"等更基本的成分构成。

**结论**：苹果不是 0 级概念，它是 E-06 认知基线用来演示"0 级属性随感知基线变化"的案例。真正的问题不是"0 级概念是什么"，而是"**对谁来说是 0 级**"。

同一原则适用于灵镜与蜉蝣的差异：蜉蝣有感官，灵镜只有文本——"红色"对蜉蝣是 E0，对灵镜是 ≥E1。

> **范畴论视角的边界**：对象的性质不取决于对象本身，而取决于它所在的范畴与态射关系。此主张属于表征层的刻画——它说明**我如何切分**这个对象，不对对象在 `W` 中是否独立存在作断言。
