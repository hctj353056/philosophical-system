# L1.2 个体模型不等于世界

## 区分
- `W`：真实世界，作为本体系所讨论的现实对象。
- `M_i`：第i个主体的意义世界或认识模型。
- `C`：主体间通过交流、共同实践与公共检验形成的共享模型。

## 命题
主体关于世界的描述、概念与理论是认识模型，不应仅凭它们被构造出来或被广泛接受，就将其与所描述的世界直接等同。

## 重要推论限制
`M_i 与 C 更一致 ≠ 已证明更接近 W`

主体间一致性有助于协调理解，但共享模型仍可能包含共同偏误。

## 检验方向
比较模型的预测、解释、干预表现及其在新条件下的稳健性；同时明确每种检验的适用范围和失败条件。

## 下游细化：表征结构

本命题区分了 `Mᵢ` 与 `W`，但没有说明 `Mᵢ` 的内部结构。该细化由概念体系（E 层）承担：

- `E-06 认知基线`：一个概念是否"不可再分"，取决于认知主体的感知基线；对象的性质取决于它所在的范畴与态射关系。
- 这类主张属于**表征层**，描述 `Mᵢ` 如何切分被认识的对象，**不**对 `W` 的存在与独立性作断言。

因此 `E-06` 的依赖关系挂本命题（细化），不挂 `L1.1`。见 `元规则/跨体系接口.md` 接口①。

## 状态
本命题首先是体系内的概念区分。它不单独证明W的完整本体论。
