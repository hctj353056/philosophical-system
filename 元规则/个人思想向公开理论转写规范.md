# 个人思想向公开理论转写规范（试行）

> 本文件规定：如何把个人思想空间中的表达，转写为适合公开哲学体系的文本。它是写作与整理方法，不是哲学命题，也不预先判定任何思想为真或为假。
>
> 状态：试行稿 · 2026-11-27

## 1. 基本区分

- **个人思想空间**：保存思想发生、体验、探索、假设与未完成推论的地方。可以保留片面、强烈主观、极端唯心或暂时不自洽的表达。
- **公开理论空间**：对外呈现经过概念澄清和论证整理的思想。公开文本需要承担更高的表达、论证、来源与规范责任。
- **转写**：将思想从一种表达场景转换到另一种表达场景。转写不是简单润色，也不等于主体已认可最终版本。

两者不是简单的真理等级。个人化表达不因其个人性而失去研究价值；公开形式也不自动使内容更真实。

## 2. 不可违反的原则

### 2.1 保留来源，不覆盖原意

1. 原始表达应尽可能按原文保存，不能用公开稿覆盖原文。
2. 转写稿应标明它是整理者的版本，并链接或指向来源。
3. 若原文存在歧义，应保留歧义或列出不同解释，不擅自选定一种并伪装成原意。
4. 不得为了让公开文本更整齐、温和、符合常见观点或更容易通过审查，而改变主体实际表达的立场。

### 2.2 重建意图，再进行论证

先尝试回答：
- 主体当时试图解决什么问题？
- 关键术语在当时语境中是什么意思？
- 这是体验描述、个人立场、事实判断、假设、规范主张，还是研究问题？
- 该表达的确定程度有多高？

在完成忠实重建前，不先批判、反驳或替主体补全理论。

### 2.3 不把表达强度转化为证据强度

“我确信”“必然”“绝对”等词可以出现在原始表达中，但公开稿不能仅因原文语气强烈，就将其当作已证成的普遍命题。

应根据论证与证据选择表达强度，例如：
- 个人立场：“我倾向于认为……”
- 工作假设：“本文暂设……”
- 条件性主张：“在条件 X 下，可能出现……”
- 普遍命题：只有在概念、推导和适用范围得到充分说明后，才使用更强措辞。

### 2.4 公共规范与真理判断分开

公开稿应遵守适用的法律、平台规则、学术诚信、隐私与版权要求；同时明确：

- 合规不等于真实；
- 不合规的表达形式不自动证明其思想内容为假；
- 为满足公开规范而需要删减或改写时，应说明改动范围及原因；
- 若某内容不适合公开，应考虑不公开、抽象化或另存私有材料，而不是伪造原意。

## 3. 建议转写流程

1. **定位来源**：记录来源日期、对话或材料位置、原作者及可用链接。
2. **保存原文**：保留原始表达；校订稿与原文分开。
3. **忠实重建**：用较清晰的语言复述其意图，并标明这是整理者的理解。
4. **概念澄清**：识别关键术语、同词异义、隐含定义和概念边界。
5. **类型识别**：区分体验、描述、解释、事实判断、假设、规范、方法或开放问题。
6. **范围限定**：明确对象、条件、时间尺度、适用范围及未知部分。
7. **论证审查**：列出直接前提、推理步骤、隐含前提、支持材料、反例和替代解释。
8. **形成公开稿**：保留核心思想，但不保留未经论证的过强措辞；必要时拆分为多个不同类型的条目。
9. **来源与状态登记**：建立原文—重建—公开稿之间的对应关系，并采用适当的命题状态。
10. **主体校正**：若主体后续确认、修正或拒绝转写稿，应追加记录；不能回写或伪装成原始表达。

## 4. 转写稿建议结构

不要求每篇都使用固定模板，但应尽量包含：

- 来源与日期
- 原始表达或来源摘要
- 整理者的忠实重建
- 关键概念与定义
- 公开表述
- 直接依据与推理
- 隐含前提
- 适用范围与不确定性
- 反例、反驳条件或替代解释
- 转写者、版本与修订记录
- 主体审阅状态（未审阅 / 已确认 / 已修正 / 已拒绝 / 暂不审阅）

## 5. 何时拆分，不应强行合并

当一段个人表达同时包含不同层次时，应考虑拆分：
- 主观体验与关于外部世界的事实判断；
- 描述性判断与规范性判断；
- 形而上学承诺与经验假设；
- 个人价值立场与面向所有主体的普遍规则；
- 原始观察与 AI 推论。

拆分后应保留它们之间的关系，避免把原本有条件的观点拼接成更强的结论。

## 6. 公开稿的最低审查清单

- [ ] 是否忠实重建原意，没有擅自替主体补结论？
- [ ] 是否区分原文、整理者解释与主体后续解释？
- [ ] 关键术语是否明确？
- [ ] 是否标明前提与适用范围？
- [ ] 论断强度是否超过证据强度？
- [ ] 是否列出至少一个可能的反例或削弱条件（若适用）？
- [ ] 来源是否可追溯，未知信息是否明确标记？
- [ ] 是否检查隐私、版权、法律及公开平台规范？
- [ ] 是否明确该稿尚未获得主体确认（如确实未确认）？

## 7. 本规范的限制

本规范只能降低转写中的失真风险，不能保证完全消除解释差异。任何重建都可能包含整理者的选择；因此，转写结果应允许主体纠正，也应允许其他读者提出不同解释。

本规范本身为试行方法，后续应依据实际转写案例修订。经验记录见 [撰写与转写经验日志](../历史/撰写与转写经验.md)。
