# 跨体系接口登记

_本文件登记本仓库（L 层）与外部三套体系之间的接口关系。凡引用外部体系，必须在此登记；未登记者不视为有效依据。_

## 一、四层架构与符号主权

整合后，本仓库所在的位置与其余三套体系的关系如下：

```
L  认识论地基   本仓库 philosophical-system        → 使用 L0 / L1 / L2
E  概念词汇表   概念体系 v1.0                       → 改称 E0 / E1 / E2 / E3
S  运行规格     心智模型完整版                       → 改称 S0 / S1 / S2 / S3
O  建模对象     四层认知框架（EntityRecord 等）       → 保持具名，不编号
```

**符号主权**：`L` 前缀在本体系生态中专指论证层级，其他层不得占用。理由：本仓库是对外发布物，编号需最稳定；E 层与 S 层属内部资产，改名成本低。

四套体系的对应文件见 `分层/` 目录：
- `分层/E-概念体系-v1.1.md`
- `分层/S-规格层映射.md`
- `分层/O-建模对象层.md`

## 二、接口①：L 层 → E 层（表征结构细化）

E 层的概念体系描述的是个体意义世界 `Mᵢ` 的内部表征结构——如何切分、命名、分级。它**不**对真实世界 `W` 的存在与独立性作断言。

| 接口 | 上游命题 | 下游概念 | 关系 | 说明 |
| --- | --- | --- | --- | --- |
| I-1 | `L1.2` 个体模型不等于世界 | E-13 认知基线 | 细化 | 认知基线讲"性质取决于所在范畴"，属于 `Mᵢ` 的内部结构，是 L1.2 的下游细化 |
| I-2 | `L1.1` 现实不完全取决于特定主体的认识 | —（无下游） | 边界 | L1.1 是本体层承诺；E 层不得援引 L1.1 支持任何表征主张 |

### 关键澄清（曾误挂）

**E-13 认知基线曾被视为与 L1.1 冲突，实为误认。**

- `L1.1` 管本体层：`W` 存在，且不被特定主体的认识决定。
- `E-13` 管表征层：主体如何切分、命名、分级这个 `W`，取决于其范畴框架与感知基线。
- 一句话：**现实的独立性 ≠ 我的表征方式的唯一性。**

承认"红色"对先天盲人不是 0 级概念，并不等于承认"红色"由主体创造。因此 E-13 应挂 `L1.2`，不挂 `L1.1`。

两条命题均已增补边界声明，防止再次误读：
- `L1.1` 增补「推论限制」：只主张 `W` 的独立性，不主张表征方式唯一。
- `E-13` 增补「边界声明」：只谈 `Mᵢ` 表征结构，本体立场由 `L1.1` 承载。

## 五、D 层对 L 层的实质补强

| O 层 | 对应 L 层 | 补强内容 |
| --- | --- | --- |

因此 `体系总纲.md §2` 的 `Mᵢ` 定义已修订为时间下标化形式 `Mᵢ(t)`，自我指涉部分记作 `Mᵢ[Mᵢ]`。

## 六、跨层修订传导规则

### 向下传（命题修订 → 下层检查）

修订 `L` 层命题后，必须依次检查：

1. `E` 层是否有概念建立在被推翻的前提上 → 该概念需标注 `contested` 或重构；
2. `S` 层是否有不变式依赖该概念 → 该不变式需重新论证；
3. `O` 层建模对象是否需重设 → 若字段定义基于错误分类，需重建。

### 向上反馈（下层异常 → 命题挑战）

`S` 层或 `O` 层发现下列情形时，必须显式上报至 `L` 层，不得就地消化：

- 某条款反复被违反，且原因不是执行错误；
- 某验证长期 PASS 但外部表现持续不符（验证项测错了对象）；
- 为避免违规而不断增设例外（底层分类需要重构）。

**禁止只在底层打补丁。** 补丁越顺手，越应怀疑当前处于局部最优（`L1.7`）。一个从不向上反馈的规格系统，是"修无可修"的活样本。
